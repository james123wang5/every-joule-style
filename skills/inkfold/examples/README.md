# 第一期的装置代码（只供阅读）

这些文件来自第一期《抛体运动》（高中物理第五章）。它们是照这套引擎打磨过的真实装置，写新装置时可以照着学写法。它们没有接进 `template/`；要借用某一段，就把需要的部分抄进新书的 `src/lessons/`（import 路径和 `src/lessons/` 下一致）。

| 文件 | 内容 | 值得学的写法 |
|---|---|---|
| `l1.js` | 曲线运动：砂轮火花、链球转台、冰球场（3 个装置） | 多装置切换；`Streaks` 发光火花；点一下转、再点松手的两段式交互；拖动力的箭头；冰球撞围板反弹 |
| `l2.js` | 运动的合成：小船过河、气泡管小车（2 个装置） | 参数开关（水速、小车）用 `onSwitch` 重置；拖船头改方向；`this.stat` 画彩色静态线；芦苇、卵石这类点缀 |
| `l3.js` | 实验：同时下落仪（全景 / 特写） | 同一装置两种尺度；弹簧剖面（`this.dyn` 每帧画螺旋线）；频闪残影；点数字卡作答的挑战 |
| `l4.js` | 平抛：抛射台、斜面上的平抛（2 个装置） | 物理模型单独放在 `projectile-model.js`；轨迹、速度分解箭头；落点判定和过关 |
| `l5.js` | 斜抛：投掷场、喷泉、射程图（3 个装置） | 绕点转的炮管 + 量角器；保留多条轨迹和小旗；空气阻力开关；`Streaks` 做发光水流；可拖动选点的图表卡 |
| `projectile-model.js` | 平抛的物理模型（米、秒，与画面无关） | 模型和画面分开的范例 |
| `lessons.js` | 五课的文字 | 每课左页文字、图注、开关、演示字幕的写法和字数 |
| `matter.js` | 第一期的附页（旧版，文字写死在代码里） | 只看测验题、图例、给老师的写法；新书的附页文字写在 `config.js` 和 `quiz.js` |
