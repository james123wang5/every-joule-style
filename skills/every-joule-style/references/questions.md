# 问答：问什么、怎么问、默认是什么

原则：
- 一轮最多 4 个问题，一次问完，不要一个一个问。
- 每个问题把推荐项放第一个，写明“（推荐）”；所有问题都有默认值。
- 告诉用户：**回复“默认”就全部按推荐来**。用户没回答的问题也按默认。
- 有提问工具（例如 Claude Code 的 AskUserQuestion）就用它；没有就发一条编号消息，每题列出选项字母，用户可以回“1A 2B 3 默认 4A”。
- 用户的语言是什么就用什么语言问。
- **用户已经说清楚的就不再问**（例如已经给了课数、读者），直接写进你的方案里请他一并确认；第一轮可以少于 4 题。

## 第一轮（读完材料之后）

### 1. 分课表

先根据材料拟一个分课表，再问用户行不行。每课一个跨页（左页文字、右页装置），一课只讲**一个**核心想法；材料多就多分几课，不要把两个想法塞进一课。

```
我打算分成 5 课：
1. 曲线运动——速度沿切线
2. 运动的合成与分解——小船过河
3. ……
（标 * 的知识点是材料里没有、我补充的）
```

选项：按这个分（推荐）/ 合并成更少的课 / 拆得更细 / 我来改。默认：按拟的分。
建议 3–8 课。超过 8 课时提醒用户：每课的装置都要单独写，工作量和时间会成倍增加，可以先做前几课。

### 2. 书名和封面

书名默认取主题（如“抛体运动”），副标题默认“一本会动的书”（英文 “A book that moves”）。封面布面颜色：

| 选项 | cloth | sheen | foil（烫金，RGB 0–1） |
|---|---|---|---|
| 芥末黄（推荐） | `#c8961e` | `#f3d79a` | `[0.96, 0.5, 0.24]` |
| 深蓝 | `#23345e` | `#8ea0d8` | `[0.95, 0.78, 0.42]` |
| 墨绿 | `#2f4a3a` | `#9fc2a8` | `[0.95, 0.78, 0.42]` |
| 酒红 | `#6b2430` | `#d89aa4` | `[0.95, 0.8, 0.5]` |

### 3. 读者和难度

选项：按材料推断（推荐，说出你推断的结果，如“高中一年级”）/ 小学高年级 / 初中 / 高中 / 大学和成人。
难度影响：用词、公式多少、是否给“进阶”内容、测验题难度。默认：按材料推断。

### 4. 附页要哪些（可多选）

- 扉页和“这本书怎么用”（front）
- 本书的记号和目录（contents）
- 索引和公式一览（index）
- 测验（quiz，默认每课 2 题，全书至少 4 题、最多 10 题；课少时每课多出几题，否则测验页大片空白）
- 参考来源和给老师（sources）

默认：全要。写进 `config.matter`，例如只要目录和测验：`{ before: ['contents'], after: ['quiz'] }`。

### 不问、直接用默认的

- 语言：跟材料走（中文 `zh` / 英文 `en`）。
- 字体：引擎固定（中文思源宋体 + 霞鹜文楷，英文 Source Serif 4 + Caveat）。
- 音效：自带 19 段 CC0 录音，默认可用（读者在控制条里开关）。
- 自动演示：每课 5 个镜头 × 2 秒。

## 第二轮：每课的装置方案（必须确认）

用一张表，每课一行或一小段。写清楚到用户能想象出画面：

| 课 | 装置（1–3 个，用“装置”开关切换） | 学生动手做什么 | 仪表架 / 纸签读什么 | 开关 | 预测题 | 挑战 |
|---|---|---|---|---|---|---|
| 1 滑下斜坡 | 缓坡、陡坡 | 把小球沿坡往上拖，松手滑下 | 杯子：高度 h、速率 v；纸签：起点高度 | 坡度：缓 / 陡 | 同一高度，陡坡和缓坡谁到底更快？ | 让小球到坡底正好 2.0 m/s |

构思要点（详见 `subjects.md` 和 `style.md`）：
- 装置要能**直接拖、点装置本身**，而不是拖滑块。
- 读数要能**一眼看出规律**：两只杯子对比、一条轨迹、一圈等高线……
- 预测题要针对一个常见误解，挑战要逼学生用装置去试。
- 一课最多 3 个装置；每个装置都要比书页上的普通插图大、清楚。

然后问：“这样做可以吗？要改哪一课？”选项：按这个做（推荐）/ 我要改几处。用户说“你定”或“默认”就按表做。

## 第 1 课做完后

给用户看第 1 课的截图（`check-shots/` 里的默认视角、每个装置、演示镜头），或 `npm run dev` 的地址。问：“风格和质量满意吗？满意我就照这个做其余各课。”有意见先改第 1 课，再往下做。
