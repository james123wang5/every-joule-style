# 风格规范

## 最关键的一条

**写实的书和桌子，衬着手绘墨线插图。** 书、桌、光、阴影全按真实感渲染（引擎已经做好）；只有右页的插图是钢笔墨线加排线，像铜版画。不要给书页、桌面加墨线滤镜，也不要把插图做成写实材质。

## 插图

- **一屏一个大装置**，放大到 1.3–2 倍，周围留白。宁可多做几个装置用开关切换，也不要挤在一起。
- 每一条线都是钢笔笔画：主轮廓 0.9–1.1，次要的棱 0.6–0.8，刻度和纹理 0.4–0.6（`faint`）。直尺画的东西（刻度、网格、导轨）加 `taper: false`。
- 暗面用排线，不用灰色。排线方向跟着物体走：木头顺纹，金属竖向，球斜交叉，大平面疏而淡。
- 颜色很克制：纸色 + 墨色为主，只有“量”才上颜色：
  - 蓝 `#2a5db0` / 发光蓝 `#2f7bff`：速度、水平方向、冷的东西
  - 红 `#b8412e` / 发光橙红 `#ff4a2a`：力、竖直方向、热
  - 橙 `#ff7a1c`：能量、高度
  - 其他量自己选，但全书统一，并写进 `config.legend`
- 发光的只有“读数”和“能量”：仪表架的液体、火花、水流、灯。发光体会把彩色光溢到附近纸面上，很好看，但每屏 1–3 个就够；两只杯子尽量用不同颜色（同色会把一片纸染成一种色）。
- 默认视角是从正前上方往下看：扁平的装置（转盘、地图）显得“立不起来”，要给它加高度——底座、支架、立柱、竖起的标尺或背板。
- 纸签是米色小卡，标题小号灰字 + 手写读数，挂在物体旁边，不压住任何东西。
- 加一两处小点缀让画面有生气（岸边的芦苇、沙盘里的小石子、小旗），但别喧宾夺主。

## 版式（引擎已经排好，你只控制文字量）

- 左页：课号、大标题、两段加粗导语、核心框、关键词、预测题、翻盖“为什么？”；页边栏是手写“你的数据”和挑战。
- 右页：插图占大半，下面两行：图注 + 参数开关；动手提示 + 装置开关。
- 文字少。左页放不下就删字，不要缩字号。

## 节奏

- 翻到一课：钢笔 3–4 秒把插图画在纸上（先大轮廓，后细节），然后插图从纸面立起来。
- 第一次到这一课会自动放演示：5 个镜头，每个 2 秒，字幕在控制条里，最后一句是“轮到你：……”。
- 操作的反馈要即时：拖的时候读数就在变，不要等松手。
- 物理过程可以慢放（0.2–0.5 倍），让眼睛跟得上；读数仍按真实值。

## 交互

- 直接拖装置本身：拖小球、拖炮管、拖活塞、拖小旗。图注旁的小字开关只用于切换“情形”（坡度、水速、有无阻力、装置）。
- 鼠标移到能拖的东西上会变成手形；能点的东西用 `cursor: 'pointer'`。
- 每课都有一个挑战，完成后页边盖章；挑战要试几次才能成功，但不要难到要猜。

## 语气

- 像一位耐心的老师在旁边说话：短句、具体、口语化但准确。
- 先现象，后道理；先让学生猜，再让他看，最后告诉他为什么。
- 不说“显然”“众所周知”；不堆术语，必要的术语放进关键词并给一句话定义。
- 演示字幕像旁白：“松手：高度换成速度。”

## 声音

引擎自带的 CC0 录音：翻页、钢笔沙沙声、打勾、翻盖、盖章、弹射、落地、落进桶、风声、砂轮。读者在控制条里打开声音。新装置用最接近的那个；需要新声音就从 Freesound 找 CC0 录音放进 `public/audio/`，并在那里的 README 记出处。
